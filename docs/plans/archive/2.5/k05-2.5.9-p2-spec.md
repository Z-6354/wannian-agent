## 0. 一句话验收（可测语义）

> 对某会话已落库的后台 Task：  
> `GET /api/conversations/{cid}/background-tasks` 返回列表（status、taskType、inputPreview、nextFireAt、schedule 摘要、终态摘要字段）；  
> `GET .../background-tasks/{taskId}` 返回详情（含 resultPreview / errorCode / lastFiredAt / completedAt 等可读字段）；  
> `POST .../background-tasks/{taskId}/cancel` 调用 `TaskRuntime.requestCancel`，映射 Accepted / AlreadyTerminal / NotFound。  
> chat 侧栏在会话激活时展示该列表；非终态行可取消；定时行可见 `nextFireAt`；点开行见详情。  
> 转录中 Busy 虚线气泡（`taskDelivery`）可点击/链到对应 task（高亮侧栏行或打开详情）。  
> **不**新增消息中心 toast；**不**改 2.5.4–2.5.8 执行/交付状态机语义。

## 4. 新建 / 改形状的类型

### 4.1 `BackgroundTaskView`（新建 · 读投影 · app 或 api）

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `taskId` | string | Task id | 非空 |
| `conversationId` | string | 所属会话 | 非空 |
| `status` | string | 当前 status 名 | 非空 |
| `taskType` | string | 类型名 | 非空 |
| `notifyPolicy` | string | | 非空 |
| `inputPreview` | string | input_json 截断 | 默认 ≤160 |
| `resultPreview` | string? | result_json 截断/脱敏 | 可空 |
| `errorCode` | string? | 若可从 result/payload 取 | 可空 |
| `nextFireAt` | string? | ISO | 定时可有 |
| `lastFiredAt` | string? | ISO | 可空 |
| `completedAt` | string? | ISO | 终态可有 |
| `createdAt` | string? | ISO | 列表排序用 |
| `scheduled` | boolean | scheduleSpec≠null | |
| `scheduleSummary` | string? | 人话短摘要（relative/at/every/cron） | 可空 |
| `cancelable` | boolean | 非终态则可取消（推荐） | |

列表项可用同形状的子集（U2）。

### 4.2 HTTP 路径（钉）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/conversations/{conversationId}/background-tasks` | 列表；query 可选 `includeTerminal=true`（默认 true；U3） |
| GET | `/api/conversations/{conversationId}/background-tasks/{taskId}` | 详情；校验会话归属 |
| POST | `/api/conversations/{conversationId}/background-tasks/{taskId}/cancel` | 取消 |

错误体对标 TaskReview：`{ code, detail }` + `HttpMapping.statusForPublic`。

### 5.2 `BackgroundTaskRepository` 扩读

| 项 | 内容 |
|----|------|
| **行为** | list/find 增加 `result_json`、`last_fired_at`、`completed_at`、`created_at`（可新方法 `listViews` / `findView` 避免胀 `TaskDraft`） |
| **禁止** | 改 V024 CHECK；发明双账本 |
| **本号** | **真** |

### 5.3 `BackgroundTaskController.cancel`

| 项 | 内容 |
|----|------|
| **行为** | 校验会话归属 → `taskRuntime.requestCancel` → map 结果 |
| **Accepted** | 200 `{ status: "CANCELLED", taskId }`（或等价） |
| **AlreadyTerminal** | 409 或 200+already（**U4** 推荐 409 CONFLICT） |
| **NotFound** | 404 |
| **本号** | **真** |

### 5.4 chat 侧栏

| 项 | 内容 |
|----|------|
| **行为** | 激活会话 → `listBackgroundTasks`；渲染列表；详情抽屉/展开；取消按钮调 API 后刷新 |
| **刷新** | 切换会话必刷；可选：Turn completed / Outbox 后轻量刷新（U5） |
| **本号** | **真** |

### 5.5 虚线关联

| 项 | 内容 |
|----|------|
| **行为** | `taskDelivery` 项若有 taskId（contentJson 或 outbox payload）→ 可点；聚焦侧栏对应行 |
| **无 taskId** | 仅样式，不报错 |
| **本号** | **真**（最小：点击打开侧栏并高亮） |
