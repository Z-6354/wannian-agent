## 3. 三类测试清单（不得缩成四字）

### 3.1 （a）无上下文子代理独立审

| 项 | 要求 |
|----|------|
| 代理 | **新开**无本对话历史；只给路径/P2/实施单/验收包/必要 diff |
| 覆盖 | 至少各一代理（或一轮分号）：**2.5.7、2.5.8、2.5.9、2.5.10**；另可一轮 **总览缺口审**（对照 k05 不变量 + §6 禁区） |
| 交付 | 每号：通过/缺口表（路径+断言+证据）；主会话核对后回写实施单 status |
| 禁止 | 用有上下文主会话自审冒充；摘要代审无文件证据 |

### 3.2 （b）软件窄测 / 回归

| 项 | 要求 |
|----|------|
| 编译 | `mvn -s <HANAGENT>/.mvn/settings.xml -pl app -am compile` SUCCESS |
| 窄测 | 优先跑与 Task/交付/会话相关的既有测（**C3** 钉命令集）；无专用测时至少 compile + 可指向的既有回归子集 |
| 本号可新增测 | **允许**（清理版授权）；新增须服务缺口/不变量，禁止无关扩测 |
| 记录 | 命令、模块、结果、日期写入 `k05-2.5.11` REVIEW / 实施单 |

**推荐窄测候选（实施时按仓内实际类名裁剪 · C3）：**

```text
与 Task / Turn / 交付 / 会话卫生相关的 *Test
+ 全量或 app,kernel 既有安全子集（失败则先判是否本周期回归）
```

### 3.3 （c）真人 live（忌 Fake）

| 场景 | 必须观察到 |
|------|------------|
| L1 审核 | 模型提案后台 Task → UI 确认后才落库；驳回不落 |
| L2 Busy | 对话进行中完成后 → 虚线附带；可点到侧栏 task |
| L3 Idle | 无进行中对话时 → 系统唤模主动汇报（非仅模板静默） |
| L4 定时 | SCHEDULED 到期晋升执行 → 可见交付；侧栏见 nextFire / 终态 |
| L5 侧栏 | list/detail/cancel；跨会话 404 |
| L6 消息中心 | 顶栏通知出现完成/失败；归档关闭/撤销不退化；点任务进侧栏 |
| L7 禁区 | 无 WORLD_TICK 用户推；未确认不插 Task |

约束：`wannian.model.mode=live`；缺密钥则标未就绪停测，不得 Fake 冒充。
