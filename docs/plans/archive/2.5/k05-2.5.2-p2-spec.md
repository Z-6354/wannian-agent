## 0. 一句话验收（可测语义）

> 在无 Committer 接线的前提下：调用方能用 `TaskRuntime.prepare` 从合法 `TaskProposal` 得到带完整字段的 `TaskDraft`（立即或定时；定时含已 resolve 的 `next_fire_at`）；非法时机/重复/DSL 被明确拒绝。

> **本号不**改 `SqliteTurnCommitter` / FrozenPlan、**不**跑工具、**不** tick、**不**接 Loop。

### 4.3 `ScheduleSpec`（判别联合 · 字段表）

#### `ScheduleSpec.Relative`

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `type` | 常量 `"relative"` | 判别 | 非空 |
| `offset` | `String` | 相对时长，如 `20m`/`2d`/`48h` | 非空；仅允许显式相对，**禁止**与 every 歧义的裸语义混用 |
| `resolvedAt` | `Instant?` / ISO `String?` | Resolver 填：解析后的绝对点 | prepare 成功后非空 |

#### `ScheduleSpec.At`

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `type` | `"at"` | 判别 | |
| `at` | `Instant` 或带 offset 的 ISO `String` | 单次绝对时刻 | 必须带时区/offset；禁裸本地无区 |

#### `ScheduleSpec.Every`

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `type` | `"every"` | 判别 | |
| `everyMs` | `long` | 间隔毫秒 | >0；建议上限 P2 **D4** |
| `anchorAt` | `Instant?` | 对齐锚点 | 可空；空则用首次 resolve 时刻 |

#### `ScheduleSpec.Cron`

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `type` | `"cron"` | 判别 | |
| `expr` | `String` | 5 字段 cron（分 时 日 月 周） | 非空；非法则拒绝 |
| `tz` | `String` | IANA，如 `Asia/Shanghai` | 非空；与行级 timezone 一致或写入行级 |
| `domDow` | 文档常量 | 语义 **OR**（Vixie/croner） | 实现注释写死；不做静默 AND |

**立即执行：** `TaskDraft.scheduleSpec == null`（或显式缺省）；`nextFireAt == null`。

## 5. `ScheduleResolver` 方法详单

### 5.1 `resolveForPrepare`

| 项 | 内容 |
|----|------|
| **声明** | `TaskDraft resolve into nextFire / normalizedSpec`：建议 `ResolvedSchedule resolve(ScheduleSpec? spec, String timezone, Instant now)` |
| **所属** | `kernel.task.ScheduleResolver`（接口）+ app 默认实现 |
| **参数** | `spec`：null=立即；`timezone`：IANA；`now`：时钟 |
| **返回** | 立即：`nextFireAt=null`，`spec=null`；定时：规范化 spec + 首个 `nextFireAt` |
| **行为** | relative→算 at 并写入 `resolvedAt`；at 校验 offset；every 用 now/anchor 算下一火；cron 用库按 tz 墙钟算下一火 |
| **失败** | 非法 expr/offset/tz → 抛受检或返回 Result；prepare 映射为拒绝（**D1** 错误码） |
| **副作用** | **无**写库 |
| **本号** | 真实现 |

### 5.2 `advanceAfterFire`（本号可实现纯函数；Ticker 在 2.5.8 调用）

| 项 | 内容 |
|----|------|
| **声明** | `Optional<Instant> advance(ScheduleSpec spec, String timezone, Instant lastFiredAt)` |
| **返回** | 单次（relative/at）→ empty（应终态）；every/cron → 下一 `nextFireAt` |
| **失败** | 非法 spec → 明确失败 |
| **副作用** | 无写库 |
| **本号** | 建议真实现，便于 2.5.8 直接用 |

## 6. `TaskRuntime` 方法详单

### 6.1 `prepare`

| 项 | 内容 |
|----|------|
| **声明** | `TaskDraft prepare(TaskProposal proposal, OriginTurn origin)`（origin 可已在 proposal 内，二选一钉死实施单） |
| **所属** | `TaskRuntime` / `DefaultTaskRuntime` |
| **参数** | 合法 Proposal；见 4.5 |
| **返回** | 完整 `TaskDraft`（含预分配 `taskId`、Resolver 结果、`initialStatus`） |
| **行为** | 校验 source/type/spec 组合；调 Resolver；填默认 retry/notify；**不写库** |
| **失败** | SYSTEM / WORLD_TICK / MEMORY_REVIEW / 非法 DSL / input 超限 / 立即+多次冲突 → 拒绝（异常或 Result；**D1**） |
| **副作用** | 无 DB；可生成 UUID |
| **本号** | **真** |

### 6.2 `dispatchNext` / `acceptResult` / `requestCancel`

| 项 | 内容 |
|----|------|
| **声明** | 接口签名齐备（参数表实施单按后号需要最小集） |
| **行为** | 本号 **明确未启用**：失败/Rejected，**禁止**空成功 no-op |
| **副作用** | 无 |
