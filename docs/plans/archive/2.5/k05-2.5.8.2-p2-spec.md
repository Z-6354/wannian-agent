上一火仍 **QUEUED|DISPATCHING（Idle）** 或 **QUEUED（Busy）** 时，下一火 `notifyDelivery` **直接 return** → §9「多次成功可见」失败。

## 锁定改法（R1–R3）

| ID | 选择 |
|----|------|
| **R1** | `notifyDelivery` / `onTaskTerminal` 传入 **`runId`**（`SubAgentRunId`）；写入 payload `runId` |
| **R2** | recurring 幂等：**仅当已有活跃行且 payload.runId 相同** 才跳过；不同 runId **允许并存** |
| **R3** | cancel 等无 runId：保持「任一活跃则跳过」旧语义（防双取消通知） |
