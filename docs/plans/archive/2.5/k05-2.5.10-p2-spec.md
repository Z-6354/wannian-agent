## 0. 一句话验收（可测语义）

> chat 顶栏/右上角有**消息中心入口**（铃铛或等价）；打开后见统一通知列表（多 kind）。  
> 自动归档仍可关闭/撤销（语义不退化；API 可迁到统一 notices，旧 `/notices/archive*` 兼容或薄转发）。  
> Task **成功交付**（Busy 虚线 flush 或 Idle 助手消息落地后）→ 投喂一条 `TASK_COMPLETED`（含 `taskId` / 会话 / 摘要）；点开可跳侧栏聚焦该 Task（消费 2.5.9）。  
> 定时 Task 到点开火成功且交付可见 → 可投 `TASK_SCHEDULED`（或复用 COMPLETED + `scheduled=true` 标记；**M3**）。  
> Task **失败/取消终态**且用户可见路径 → 投 `TASK_FAILED`（含 errorCode 摘要）；**不**把主 Loop HTTP 5xx 整站灌进中心（**M4**）。  
> **不**新建运营文案表/CMS；版本提醒若做仅 stub kind 或读 health 版本号对比（**M5**）。  
> **不**改 V024–V028 / 执行门闩 / Busy·Idle 协议正文。

## 1. 目标与边界

| 做 | 不做（禁区 → 归属） |
|----|---------------------|
| 统一 Notice 模型 + Store/Bus（解耦 Archive 独占） | 运营文案库 / CMS → 明确不做（本号） |
| 统一读/关 HTTP；归档 dismiss/undo 迁入或兼容 | 任务侧栏/读 API 重做 → **2.5.9** |
| 投喂：归档 · 任务完成 · 定时提醒 · 任务报错 | 改 Busy flush / Idle worker / Promote 语义 |
| 右上角弹窗 UI + 未读角标 | 独立全屏「通知站」；浏览器系统 Notification API（可选后号） |
| 点击任务类通知 → 开会话 + 侧栏 `focusTask` | WORLD_TICK；测文件；改 V024–V028 |
| 版本更新 kind 架构位（可空生产者） | 远程推送运营文案 |

**衔接**

- ← **2.4.7**：`ArchiveNoticeStore` + `/notices/archive*` + `notices.js` 是**占位**；本号吸收。  
- ← **2.5.6/2.5.7**：交付可见后才投「完成」类通知（避免执行完但用户未看见就弹）。  
- ← **2.5.8**：定时开火成功走同一交付钩；通知可标定时。  
- ← **2.5.9**：侧栏仍是详情工作台；中心只提醒+跳转。  
- → **2.5.11**：清理测 + 归档；可验「中心与侧栏分工」。

**体量：** Notice 域模型 + Store 泛化 + Publisher 接线（Archive + TaskDelivery）+ Controller + chat 弹窗 JS/HTML + wannian-ui 样式；单轮。膨胀停码回报。

## 4. 新建 / 改形状的类型

### 4.1 `NoticeKind`（新建 · 枚举）

| 取值 | 说明 | 本号生产者 |
|------|------|------------|
| `ARCHIVE` | 自动归档批次 | `ConversationArchiveService`（迁自现 Store） |
| `TASK_COMPLETED` | 任务成功且已交付可见 | TaskDelivery 成功路径 |
| `TASK_SCHEDULED` | （可选枚举位）定时专用 | **本号不强制生产者**（M3=A 用 COMPLETED+标记） |
| `TASK_FAILED` | 任务失败/取消等用户可见终态 | acceptResult / 交付失败摘要 |
| `VERSION` | 版本更新提醒 | stub 或 health 薄探（M5） |
| `ERROR` | 通用应用报错（可选窄） | **默认不做**整站 HTTP 灌入（M4=A） |

### 4.2 `UserNotice`（新建 · 读投影）

| 字段名 | 类型 | 说明 | 约束/默认 |
|--------|------|------|-----------|
| `noticeId` | string | 通知 id | 非空 |
| `kind` | string | `NoticeKind` 名 | 非空 |
| `createdAt` | string | ISO | 非空 |
| `read` / `dismissed` | boolean | 已读或已关闭 | 默认 false；本号至少支持 dismiss |
| `title` | string | 短标题 | 非空；≤80 |
| `body` | string? | 一行摘要 | 可空；≤200 |
| `conversationId` | string? | 跳转会话 | 任务/归档条目可有 |
| `taskId` | string? | 跳转侧栏 | 任务类可有 |
| `errorCode` | string? | 失败码 | FAILED 可有 |
| `payload` | object? | kind 专用（归档 items 等） | 归档保留 `items[]` |
| `actions` | string[]? | 如 `dismiss` / `undo_archive` / `open_task` | 前端按 kind 渲染 |

### 4.3 Store 形状（内存默认 · M1=A）

对标现 `ArchiveNoticeStore`：

| 项 | 约定 |
|----|------|
| 容器 | 进程内有界列表（建议 MAX≥32，可配置） |
| 幂等 | 同 `taskId`+终态+kind 重复 publish → 更新或忽略（**钉 M6**） |
| 重启 | 内存方案重启清空（与今归档一致） |
| 若 M1=B | `V029__user_notice.sql`：id/kind/created/dismissed/json_payload；本号单表够用 |

### 4.4 HTTP（钉）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/notices` 或 `/api/conversations/notices` | 未关闭列表；可选 `?kinds=` |
| POST | `/api/notices/{id}/dismiss` | 关闭 |
| POST | `/api/conversations/notices/archive/undo` | **保留**撤销归档（可仍挂 hygiene） |
| GET/POST | 旧 `/notices/archive*` | **兼容**：转发到统一 list（仅 ARCHIVE）或 301 文档说明一期双路径 |

错误体对标既有 `{ result, reasonCode }` / Task HTTP。

## 5. 方法详单

### 5.1 `NoticeCenter.publish(UserNoticeDraft)`（新建）

| 项 | 内容 |
|----|------|
| **声明** | `void publish(UserNoticeDraft draft)`（名可微调） |
| **参数** | kind、title、body?、conversationId?、taskId?、errorCode?、payload? |
| **行为** | 分配 id；入队；超 MAX 丢最旧已 dismiss 或最旧 |
| **失败** | draft 非法 → 抛 / 拒绝；**禁止**静默丢任务失败通知而不记日志 |
| **副作用** | 只写 Notice Store；**不**写 Task 账本 |
| **本号** | **真** |

### 5.2 `NoticeCenter.listOpen` / `dismiss`

| 项 | 内容 |
|----|------|
| **行为** | list 未 dismiss；dismiss 幂等（已关仍 ok） |
| **本号** | **真** |

### 5.3 Archive 迁入

| 项 | 内容 |
|----|------|
| **行为** | `publishBatch` → `kind=ARCHIVE` + payload.items；undo 成功后 `removeConversation` 语义保留 |
| **禁止** | 另起第二套归档 Store 并行长期双写（一期可适配器包装） |
| **本号** | **真** |

### 5.4 Task 投喂（交付后）

| 项 | 内容 |
|----|------|
| **挂点** | Busy：`casDelivered` / flush 成功后；Idle：助手消息写入成功后；失败终态：用户可见失败摘要确定后 |
| **成功** | `TASK_COMPLETED`（定时可加 `TASK_SCHEDULED` 或 payload.scheduled=true） |
| **失败** | `TASK_FAILED` + errorCode/resultPreview |
| **禁止** | 在 `dispatchNext` 认领时 publish；在未交付路径抢弹 |
| **本号** | **真** |

### 5.5 `NoticeController`（新建 · app）

| 项 | 内容 |
|----|------|
| **行为** | GET list → 投影；POST dismiss |
| **本号** | **真** |

### 5.6 chat 消息中心 UI

| 项 | 内容 |
|----|------|
| **行为** | 顶栏入口；面板列表按时间；角标=未读/未关数量；任务项点击 → 切会话 + `focusTask`；归档项保留撤销 |
| **刷新** | 可见时轮询（可复用 45s）+ 页面可见性唤醒；可选：Turn/Outbox 后轻刷 |
| **本号** | **真** |

### 5.7 版本 stub（M5）

| 项 | 内容 |
|----|------|
| **A** | 只建 kind；无生产者 |
| **B** | 启动/定时读 `/api/v1/health` `serverVersion` 与 localStorage 比较，变则 publish VERSION |
| **本号** | 按对话钉死 |
