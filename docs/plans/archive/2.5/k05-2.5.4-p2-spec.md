## 0. 一句话验收（可测语义）

> 对已落库且可执行的 Task（`CREATED` 或 `READY`；**不含**未到期 `SCHEDULED`）：  
> 进程内调度拍调用 `TaskRuntime.dispatchNext(budget)` 时，在门闩允许下：  
> Task→`RUNNING`，新建 `sub_agent_run`（attempt、lease token/hash/expires），经 `LocalTaskExecutor` 跑只读工具批（或本号钉死的窄占位），回报经 `acceptResult` 唯一裁决；  
> 成功→Task `SUCCEEDED`+Run `SUCCEEDED`；可重试失败→新 Run（旧 attempt 不复活）；耗尽→Task `FAILED`；lease 过期→Run `LOST` 且迟到结果 `Rejected`/`Ignored`。  
> 全进程后台槽：`active Background Run + active Memory Review Worker` **合计 ≤1**；主 Loop 可同时跑（1+1）。  
> **模型多发送窗口（2026-09-27 用户改口）：** 主 Loop 与后台/Review **可同时**调模型；**禁止**因「主 Loop 占模型」对新派 `Deferred("chat model priority")`。`DispatchOutcome.Deferred` **仅**留给 concurrency gate（槽满）。Busy≠停后台工具批。  
> 本号**不**改 TurnEngine / 不启用 BackgroundAccepted 热路径 / **不**做定时晋升与交付 UI / **不**做抢模型探针。

## 5. 方法详单

### 5.1 `TaskRuntime.dispatchNext`

| 项 | 内容 |
|----|------|
| **声明** | `DispatchOutcome dispatchNext(DispatchBudget budget)` |
| **所属** | `TaskRuntime` / `DefaultTaskRuntime` |
| **参数** | `budget.maxBackgroundRuns`：本拍最多新派后台 Run 数；默认 1 |
| **返回** | `Dispatched` / `NoneReady` / `Deferred`（**禁止**再返 `NotEnabled`） |
| **行为** | 见下「算法」 |
| **失败** | DB 瞬时错可 Deferred/抛；不得假装 Dispatched |
| **副作用** | 写 Task/Run 行；可能触发 Executor |
| **本号** | **真** |

**算法（顺序钉死）：**

1. `reclaimExpiredLeases(now)`（Run→LOST；若 Task 仍 RUNNING 且无活跃 Run → 按 retry 政策 READY 或 FAILED；**F11**：超时类失败默认可重试，算一次 attempt；耗尽→FAILED）。  
2. 若 `countActiveBackgroundRuns() + countActiveReviewWorkers() ≥ 1`（与 budget 取严）→ `Deferred("concurrency gate")`。（**仅**执行槽满；**禁止**再加「抢模型」步。）  
3. 选下一可执行 Task：`status IN (CREATED, READY)`，**排除** `SCHEDULED`；排序 **`updated_at ASC, id ASC`（F2=A）**。  
4. 同事务：`CREATED|READY → RUNNING`（CAS）+ `insertCreated` Run + 写 lease（时长=`wannian.task.run.lease-duration`，默认 **5m**，**F7/F9**；status `LEASED`→`RUNNING`）+ 生成 token。  
5. 调 `TaskExecutor.dispatch(spec)`；**F1=同步**：跑完后同拍或紧随 `acceptResult`；单次墙钟上限=`wannian.task.executor.deadline`（默认 **4m**，**F9**）。lease↔deadline 数值关系见 **F13**（实施时钉；须避免仍合法执行时被误标 LOST）。  
6. 成功派出 → `Dispatched(taskId, runId)`；无行 → `NoneReady`。  

> **已删（2026-09-27 用户改口）：** 原步「`ModelSlotProbe.isMainLoopCallingModel()` → `Deferred("chat model priority")`」。`Deferred` 类型**保留**，语义仅 concurrency gate。

### 5.2 `TaskRuntime.acceptResult`

| 项 | 内容 |
|----|------|
| **声明** | `CompletionOutcome acceptResult(SubAgentRunResult result)` |
| **所属** | `DefaultTaskRuntime` |
| **参数** | 须含 taskId/runId/attemptNo/leaseToken/成败载荷 |
| **返回** | `Accepted` / `Ignored` / `Rejected` |
| **行为** | 校验 Run 存在且 status∈{LEASED,RUNNING}；`hash(leaseToken)` 匹配；attempt 匹配；否则 `Rejected`。成功：Run→SUCCEEDED，Task→SUCCEEDED，写 `result_json`（上限见 **F9**）。失败可重试（**F11**，含 deadline 超时默认）：Run→FAILED，Task→READY（新 attempt 下拍再派）或耗尽（**F8**）→Task FAILED；`error_code` 须符合 **F12**。非法/非 durable 成功载荷→统一错误码失败分支（F12），不得假装 SUCCEEDED。重复成功回报→`Ignored`。 |
| **副作用** | 写库；**本号不**写聊天 Message / Outbox 交付 |
| **本号** | **真** |

### 5.3 `TaskRuntime.requestCancel`

| 项 | 内容 |
|----|------|
| **声明** | `CancelTaskResult requestCancel(BackgroundTaskId id)` |
| **所属** | `DefaultTaskRuntime` |
| **行为** | 无行→`NotFound`；已终态→`AlreadyTerminal`；否则 **一步到位 `CANCELLED`（F3=B）**（无外部 wait）；有活跃 Run 先 `Executor.cancel` 再 CAS 终态；尚无 Run 直接 Task→`CANCELLED`。本号不要求经 `CANCEL_REQUESTED` 两步。 |
| **副作用** | 写库；可调 Executor.cancel |
| **本号** | **真**（HTTP/UI 入口仍属 2.5.9） |

### 5.4 `TaskExecutor.dispatch` / `cancel`

| 项 | 内容 |
|----|------|
| **声明** | `DispatchResult dispatch(SubAgentRunSpec spec)`；`CancelDispatchResult cancel(SubAgentRunId runId, String leaseToken)` |
| **所属** | `TaskExecutor` / `LocalTaskExecutor` |
| **行为 · READ_ONLY_TOOL_BATCH** | 解析 `inputJson` 为只读工具调用列表；白名单工具（F4）；墙钟上限=`wannian.task.executor.deadline`（默认 **4m**）；`result_json` 上限=`wannian.task.result.max-chars`（默认 **32768**，对齐 `ToolResultSanitizer.MAX_OBSERVATION_CHARS`，**F9**）；**禁止** `save_memory` / 写关系 / 发聊天气泡。完成后构造 `SubAgentRunResult` 交 Runtime（**F1=同步**）。 |
| **行为 · USER_SCHEDULED_NOTIFY** | 本号可不跑工具：直接成功 `resultJson` 含提醒摘要占位（真交付 2.5.6/7）。 |
| **行为 · 其它 type** | `Rejected` |
| **行为 · 长跑（F10）** | **默认**：Executor deadline **砍断**为 failure（可重试，见 F11）；lease 过期仍标 Run **LOST**；是否续期由实施核心代码时与 **F13** 一并确定。硬约束：不得在仍合法执行时被误标 LOST 且不重试/不收口。 |
| **失败 / 异常（F12）** | 须接入本仓**统一异常处理机制**：失败路径写 `error_code` 必须用 `kernel.error.ErrorCodes` **已注册码**，或本号新增并注册的码；**禁止**裸字符串冒充码。可参考 `SqliteErrors`、`SafeErrorLog`、`TurnTransitionException` 边界。工具错 / deadline 超时 / 预期外异常 → failure result（带注册码）；不得写 Task 终态（由 `acceptResult`）。预期外成功载荷：至少 **durable + 非法结构** 走统一错误码失败分支；细业务校验可后号。 |
| **本号** | **真**（Local only） |

### 5.7 `BackgroundDispatchTicker`

| 项 | 内容 |
|----|------|
| **声明** | `@Scheduled` 或等价 `void tick()` |
