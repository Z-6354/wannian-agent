## 0. 一句话验收（可测语义）

> 当 Loop 经 `BackgroundPolicy` 裁决应后台化时：返回结构化 `BackgroundAccepted(TaskProposal, acknowledgementText, …)`；TurnEngine **不**立刻 `prepare`+commit。  
> 系统向用户展示**可审任务卡片**（来源提案摘要 + 时机/重复/输入摘要）；用户 **确认** 后，同一会话热路径：`TaskRuntime.prepare` → `FreezeCommitPlan`/`CommitTurnPlan` 带非空 `TaskDraft` → 同事务落库（消费 2.5.3 缝）+ 确认助手文案；用户 **驳回** 则不落 Task，回合以 Final/受控失败收口（待决 G3）。  
> 未确认前：库中 **无** 新 `background_task` 行；`BACKGROUND_NOT_ENABLED` 成功路径删除。  
> 本号**不**做 Busy 虚线 / Idle 唤模 / 定时 Ticker / 侧栏列表大改。

## 4. 新建 / 改形状的类型

### 4.1 `BackgroundPolicy`（新建 · kernel）

| 字段/方法 | 见 §5 |
|-----------|------|

无持久字段；纯裁决。

### 4.2 `BackgroundPolicyDecision`（新建 · sealed）

| 变体 | 字段 | 说明 |
|------|------|------|
| `Accept` | （可空 `notes`） | 允许后台化；Loop 可返回 BackgroundAccepted |
| `Reject` | `reason` / 建议收口 | 禁止后台化；Loop 须 Final 或 ControlledFailure |

### 4.3 `AgentOutcome.BackgroundAccepted`（改形状）

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `proposal` | `TaskProposal` | 结构化提案（替换 String） | 非空；须含 origin/source/type/input |
| `acknowledgementText` | `String` | 确认后展示/落库的短确认文案 | 非空非空白 |
| `trace` | `AgentTrace` | 脱敏 trace | 非空 |

### 4.4 `TaskReviewPending`（新建 · 持久或会话级待审）

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| `reviewId` | 新 ID 类型或 UUID | 待审单 id | 非空 |
| `conversationId` | `ConversationId` | 所属会话 | 非空 |
| `turnId` | `TurnId` | 来源 Turn | 非空 |
| `proposal` | `TaskProposal` | 待审提案 | 非空 |
| `acknowledgementText` | `String` | 预确认文案 | 非空 |
| `status` | enum | `PENDING` / `CONFIRMED` / `REJECTED` / `EXPIRED` | 本号 |
| `createdAt` / `expiresAt` | `Instant` | 待审窗口 | expires 可配置（待决 G1） |

> 落库表可用新 migration **V025**（本号允许新建；不改 V024）。若用户拍板「仅内存+Turn 挂起」则改 G2。

### 4.5 审核 HTTP DTO（新建 · app）

| 字段 | 说明 |
|------|------|
| 列表/详情 | 展示 type、时机、重复、input 摘要、ack 文案 |
| `POST .../confirm` | body: `reviewId` |
| `POST .../reject` | body: `reviewId` + 可选 reason |

## 5. 方法详单

### 5.1 `BackgroundPolicy.decide`

| 项 | 内容 |
|----|------|
| **声明** | `BackgroundPolicyDecision decide(TaskProposal proposal, PolicyContext ctx)` |
| **所属** | `BackgroundPolicy` / `DefaultBackgroundPolicy` |
| **参数** | 合法 Proposal；ctx 含预算/会话状态等（实施单钉最小集） |
| **返回** | Accept / Reject |
| **行为** | 拒绝 SYSTEM/WORLD_TICK/MEMORY_REVIEW 真跑；拒绝非法 DSL；可选：会话非 ACTIVE→Reject |
| **失败** | 不抛业务成功；Reject 带 reason |
| **副作用** | 无写库 |
| **本号** | **真** |

### 5.2 Loop 返回 BackgroundAccepted

| 项 | 内容 |
|----|------|
| **声明** | （既有 `AgentLoop.run`） |
| **行为** | 模型意图后台化且 Policy Accept → `BackgroundAccepted(proposal, ack, trace)`；Reject → 不得 BackgroundAccepted |
| **本号** | **真**（须有可测触发路径：工具/显式意图；实施单钉一种最小触发） |

### 5.3 TurnEngine · BackgroundAccepted（改）

| 项 | 内容 |
|----|------|
| **旧行为** | Held BACKGROUND_NOT_ENABLED |
| **新行为** | 创建 `TaskReviewPending(PENDING)`；向用户推送待审（SSE/既有通道，实施单钉）；**本拍 Turn** 收口策略见待决 **G4**（挂起 vs 先回「待确认」短消息但不插 Task） |
| **确认后** | `prepare(proposal)` → `FreezeCommitPlan`/`CommitTurnPlan` 带 Draft → commit；成功 COMPLETED |
| **驳回后** | Pending→REJECTED；不 prepare；回合按 G3 收口 |
| **本号** | **真** |

### 5.4 审核 API

| 项 | 内容 |
|----|------|
| **声明** | `confirm(reviewId)` / `reject(reviewId, reason?)` |
| **行为** | 校验会话归属、PENDING、未过期；confirm 触发 §5.3 确认路径 |
| **失败** | 非法状态 → 注册 ErrorCodes（如 `ILLEGAL_STATUS`） |
| **本号** | **真** |

### 5.5 UI（最小）

| 项 | 内容 |
|----|------|
| **行为** | chat 区可展示待审卡片：摘要 + 确认/驳回按钮；接上述 API |
| **禁止** | 完整侧栏任务中心（2.5.9） |
| **本号** | **真**（最小） |

## 9. 验收断言

```text
[ ] Policy Reject → 不得 BackgroundAccepted；无 background_task 行
[ ] Policy Accept → BackgroundAccepted 含结构化 TaskProposal；ack 非空
[ ] 未确认前：无 background_task insert
[ ] 用户确认 → prepare→commit 同事务插入；status=CREATED|SCHEDULED 与 Draft 一致
[ ] 用户驳回 → 无 insert；Pending=REJECTED
[ ] TurnEngine 不再因 BackgroundAccepted 返回 BACKGROUND_NOT_ENABLED
[ ] 过期 Pending 不可 confirm（G1）
[ ] TurnEngine / Loop 外禁区零 diff；窄编译通过
```
