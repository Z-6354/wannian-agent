## 4. 关键实现要点

### 4.1 构造器兼容

保留 `SqliteTurnCommitter(DataSource, ObjectMapper)` 测试构造：内部自建 journal + `new SqliteBackgroundTaskRepository(dataSource)`。  
`@Autowired` 三参/四参构造注入 `BackgroundTaskRepository`（优先构造器注入）。

### 4.2 Draft equals 匹配

`mismatchedFrozenPlan`：`Objects.equals(frozen.taskDraft(), plan.taskDraft())`（record 语义）。

### 4.3 插入失败

`insertFromDraft` 抛运行时/SQL → 外层事务 rollback（与 Memory 同模式）；**禁止**吞掉后继续 delete frozen plan。

### 4.4 TurnEngine

本号**零改**；继续旧 `FreezeCommitPlan.of` → task=null。
