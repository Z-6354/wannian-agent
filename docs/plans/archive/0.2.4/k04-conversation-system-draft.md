## 1. 本版目标

把 `/chat/` 做成可长期使用的单用户会话系统：实时看到回复正文和工具过程；回合与工具均能展开详情；重开页面回到最近一次对话；左侧管理、搜索、重命名、归档和删除会话。0.2.4-A 既定的行为账本加厚仍是流式交付的前置阶段。

用户已确定：只流式展示回复正文与工具过程，不展示模型思考原文。工具详情和整体详情均可在生成中展开。隐藏推理、密钥、内部提示词和未经筛选的敏感工具原文不得投给页面。

## 3. 行为合同

### 3.1 流与历史

- 模型输出正文按增量显示；工具有开始、参数安全摘要、进度或结果安全摘要、终态。回合为外层详情，工具为内层详情；展开状态不因增量刷新而丢失。大内容截断或按需读取。
- 运行中增量是临时投影；已提交的 Message / `turn_step` 是历史真源。Outbox 只交付已提交事件。不能为了“全流式”把未提交片段伪装为可靠 Outbox 事件。
- SSE 重连用稳定事件身份或序号去重，并以服务端历史校准。刷新、切会话或重连都不重跑模型和工具；失败、取消时不把临时片段当已完成答复。
- HTTP、SSE、历史补发和 internal 使用一致的最小单用户访问策略。页面只接收允许展示的事件子集。

### 3.2 会话生命周期

- `/chat/` 打开时恢复最近一次可访问、未归档的会话，显示已提交消息与可公开的过程详情；恢复是只读操作。无可恢复会话时显示新会话空态。
- 左侧会话列表按最近活动排序，支持打开、新建、搜索、手动改名、归档、查看归档与取消归档、删除。当前会话标题替代左上角 ID。搜索覆盖标题和已提交消息正文，返回匹配会话及安全片段；结果可打开并定位到匹配消息。搜索须分页、限定当前用户范围，默认排除回收站；归档结果可通过筛选查看。查询不调用模型。
- 第一条用户消息完成提交后，异步调用模型生成短标题；临时标题立即可见。生成失败不影响聊天，晚到的自动标题不能覆盖手动标题，也不能更新已删除的会话。
- 会话切换须取消旧页面订阅或校验请求归属，防止旧流和迟到的历史请求污染新会话。URL 或浏览器状态与选中会话保持一致；重新打开网页默认最近一次会话。
- 归档保留历史并可恢复；归档会话从默认列表和默认恢复候选中排除。删除进入回收站，默认列表、搜索和最近会话恢复均排除回收站；可从回收站恢复，也可稍后清空。清空是不可恢复操作，须在产品界面明确提示。正在运行或排队的会话先完成或取消回合，再允许移入回收站；不能在后台继续对已删除会话生成内容。

### 3.3 发送、排队与停止

- 沿用已定 followup：同一会话新输入可以接收排队，按序执行；页面展示已排队及运行状态。
- Stop 作用于正在运行的回合，服务端必须真实处理取消请求并给出终态；已进入不可取消的提交阶段时页面如实说明。未执行的排队消息可撤销，不打断当前回合。
- 切换会话或关闭页面不暗中取消服务端回合；归档/删除正在运行或有排队项的会话须拒绝并提示先完成或停止，具体状态迁移见[实施设计 §3.2](./k04-conversation-system-design.md)。

| 阶段 | 主要交付 | 验收重点 |
|---|---|---|
| A · 账本 | MEMORY_WRITE、同事务边界、安全详情查询；账本与 Outbox 分工 | 回滚无半提交；敏感内容不入公开投影 |
| B · 会话读写 | 列表、消息/过程回读、最近会话、改名、归档、回收站/恢复/清空与标题/正文搜索 API | 排序/分页/状态过滤正确；全文搜索只检索已提交消息；并发改名不覆写；恢复零模型/工具调用 |
| C · 流式内核与交付 | 模型增量接口、运行中事件、Outbox 发布、SSE 游标与补发 | 正文和工具过程实时可见；提交后事件可补发；重连无重复业务 |
| D · 网页会话系统 | 侧栏、双层详情、流式渲染、会话切换、自动恢复、标题 | 刷新/重开回最近会话；展开状态稳定；旧请求不污染新会话 |

| F · 版本收口 | 自动化、断线/重启/双标签与 live 真人验收；文档清单更新 | 全链路在真实模型下运行，交付证据支持勾选 0.2.4 |

## 5. 本版完成线

1. 用户在首轮生成时看到正文增量和工具活动，可展开回合与单个工具的安全详情；终态、失败和取消状态准确。
2. 重连可补发已提交事件，运行中片段由当前运行状态校准；刷新和重连不会增加模型或工具执行次数。
3. 页面重开直接显示最近一次未归档会话及其历史；侧栏可切换、新建、搜索标题与消息正文、改名、归档、取消归档、移入回收站和恢复；清空回收站有明确的不可恢复提示。
4. 首轮自动标题成功时更新侧栏，失败时保留临时标题；用户手动标题不被后台结果覆盖。
5. 同会话连发按 followup 排队；能停止当前运行、撤销未运行项；双标签操作不会双执行。
6. 行为账本记忆写入可追溯，脱敏与事务回滚成立；公开事件不泄漏隐藏推理、密钥或内部提示词。

## 6. 详情可见性原则

- **详情粒度**：默认展示脱敏后的参数与结果摘要；如需完整工具结果，按工具级可见性策略和大小上限扩展。
