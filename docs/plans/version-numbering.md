## 三层含义

| 层 | 写法 | 含义 |
|----|------|------|
| **产品档** | **`v1` / `v2` / `v3`**（带 **v**） | 更大边界 |
| **实现周期** | **`2.1` … `2.7`** | 一块主线主题；例 **2.5** = Task |
| **小版本** | **`2.5.1` …** | 周期内单步 |

规则：

- 旧产品档 `v0.1` / `v0.2` / `v0.3` → **`v1` / `v2` / `v3`**
- 旧实现周期 `0.2.5` → **`2.5`**
- 新周期：**`2.x.1` = 规划计划版**；第一实现从 **`2.x.2`** 起；清理版 = 本周期最大号
- 旧字母阶段（实现起步）：如 `0.2.5-A` → 现表约 **`2.5.2`**（首实现）；**勿**再把 A 当成规划号
- 口语「当前 2.5」= 实现周期；「产品档 **v2**」须带 **v**
