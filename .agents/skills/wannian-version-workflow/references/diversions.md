# 中途分流：新想法 · 旁线 · backlog · 小改

正常层内步骤 → [layers.md](./layers.md)。本文件**只**管偏离主线时的路由。

---

## 1. 用户提出新想法（强制先问）

**先问清、再动手。** 禁止默认塞进当前实现版 MANIFEST；禁止不经确认改 roadmap。

```text
新想法 / 新需求 / 新功能点
    ▼
【必问】是否在本实现周期（当前如 roadmap 上的 2.x）内实现？
    ├─ 是 →「本周期纳入」→ 再走层2/层3 相应步骤
    └─ 否 → 选定目标实现周期 → 写入该周期计划/roadmap → 本周期不改码
```

| 用户选择 | AI 动作 |
|----------|---------|
| **在本周期** | 说明对目标/阶段表影响；必要时重跑层2③–⑤ + 规划 P1/P2（对话重审）；进行中实现版若膨胀则先停码补规格；体量仍须单轮可切 |
| **不在本周期** | 列出未收口 2.x + 可新开周期；选定后写入对应计划与 roadmap；**本周期阶段表不自动改** |
| **暂不确定 / 备忘** | 记 backlog（如 `docs/plans/`）；标「未排期」；禁止偷塞本周期 |

若实际是**改产品档边界**（升 v3 等）：先 overview+roadmap 变更 + 用户确认，再谈落入哪个实现周期。

## 2. 其它分流

```text
开/继续实现周期（无新想法）？ → layers.md 层2
周期内下一 2.x.n？           → layers.md 层3 + 对应类型细则
审阅中提问？                 → review-protocol.md §答疑
改计划/修规格？              → review-protocol.md §改计划
旁线专题？                   → §3
明确小改（几行）？           → 可跳过全套阶段门；长成半个 2.x.n 则补规格门
```

---

## 3. 旁线与 backlog

旁线可缩版走层2–层3，排期独立。新想法定为旁线：仍先经 §1 确认「非本主线周期」，再选定旁线计划或某周期并入。  
**backlog 未排期项禁止塞进进行中规格 MANIFEST。**
