# 可审深度 · 字段模板

对标历史「可审的 0.2.5-A / 现首实现级」。  
**无流程**：过门见 [planning-gates.md](./planning-gates.md)；对话见 [review-protocol.md](./review-protocol.md)；文件卡见 [implement-draft.md](./implement-draft.md)。

写法习惯：每一块尽量「做什么 → 对标谁 → 为什么 → 本仓怎么落」。

---

## P2 · 实现版必补维度

文档写全 + 对话须覆盖：

| 维度 | 落实 |
|------|------|
| 目标与边界 | 做/不做；前后号衔接；禁区归属 |
| 代码文件列表 | 路径 + **修改方式**（增加/删除/修改/审查）+ 一句话目的；禁止集另列 |
| 实现理由 | 为何此切、守何不变量 |
| 同业参考 | 项目/文档名；可吸收/勿抄 |
| 代码锚点 | 现码路径与行为（已核实） |
| **新建对象/类型** | §对象 |
| **新建或改签名的方法** | §方法 |
| 类型/表/事务 | 表列与对象字段同等要求 |
| 验收断言 | 用户可观察 |
| 待决 | 编号 + 推荐默认 |

清理版 P2 至少：覆盖前述号、三类测试清单、归档路径。

## 对象 / 类型 / 表行形状

凡本号**新建**或**实质改形状**的对象，须给字段表，不得只列类型名。

| 列 | 必填 | 说明 |
|----|------|------|
| **字段名** | 是 | 如 `taskId` |
| **类型** | 是 | Java/SQL/JSON 或枚举；可空标明 |
| **说明** | 是 | **中文业务含义**；禁止仅复述英文名 |
| **约束/默认** | 建议 | 非空、CHECK、默认、本号恒值 |
| **其它** | 按需 | 枚举取值、上限、邻字段关系、禁止写入时机 |

一对象一张表；落库与内存 Draft 分表。枚举列本号允许取值及拒绝策略。  
反模式：`TaskDraft` 只写「含 id/source 等」。

---

## 方法详单

凡本号**新建**或**改签名/契约语义**的方法：

| 项 | 必填 |
|----|------|
| **声明** | 可见性 + 返回 + 名 + 参数（名与类型） |
| **所属类型** | 接口/类 |
| **参数说明** | 每参数业务含义；可空/范围 |
| **返回说明** | 成功/空/Optional |
| **行为语义** | 做/不做；前后置状态 |
| **失败/拒绝** | 异常/错误码/Rejected；不得静默成功 |
| **副作用** | 写库/内存/事件；本号禁止的副作用 |
| **本号范围** | 建议：真实现 vs 显式未启用 |

反模式：只写「实现 TaskRuntime 四方法」。

## P1 · 切分问题详单

### 检查单

```text
[ ] 首行类型=规划；末行=清理；中间全实现
[ ] 每实现版体量 ≤ 单子代理/单轮（或记残余风险+拆分触发）
[ ] 决议与周期目标均有落点
[ ] 依赖/并行/禁区清楚
[ ] 普通实现版无「测文件/真人测」完成条件
[ ] 每问题有全字段详单（或「未发现」+检查过程）
[ ] 对话已确认切分通过；采纳项已写回阶段表
```

### 每问题字段

| 字段 | 写什么 | 禁止 |
|------|--------|------|
| ID / 严重度 | `C#`；高/中/低 + 定级理由 | 只有「有风险」 |
| 现象 | 引用草案具体句/格 | 「表有点糊」 |
| 证据 | 代码路径+行为；或契约/Q/历史规格 | 无路径猜测 |
| 为何算切分问题 | 覆盖/归属/体量/依赖/禁混 | 当错别字 |
| 若不改的后果 | 实施/验收如何失败 | 「可能不好」 |
| 改法（落到号） | 哪号交付/不做怎么改 | 「以后注意」 |
| 连带影响 | 邻号、依赖、P2 加严 | 省略 |
| 残余风险 | 改完仍在；消化门 | 假装零风险 |
| 采纳状态 | 待确认 / 已采纳 / 驳回+替代 | 口头未落盘 |

### 骨架

```markdown
#### Cn · <短标题>（严重度：高|中|低）

- **现象：** …
- **证据：** …
- **为何算切分问题：** …
- **若不改的后果：** …
- **改法：** …
- **连带影响：** …
- **残余风险：** …
- **采纳状态：** …
```
