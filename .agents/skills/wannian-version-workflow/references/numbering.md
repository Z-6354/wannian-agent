# 编号与阶段表类型

产品权威：[version-numbering.md](../../../docs/plans/version-numbering.md) · overview / roadmap / checklist。  
步骤见 [layers.md](./layers.md)。本文件**只**管号段含义与类型列硬规则。

---

## 1. 三层号段

| 逻辑 | 含义 | 正式写法 |
|------|------|----------|
| 产品档 | 更大边界 | `v1` / `v2` / `v3`（带 **v**） |
| **实现周期** | 一块主线交付主题 | **`2.1`…`2.7`**（例 **2.5**）；禁止再写 `0.2.5` |
| **小版本** | 周期内一步；单轮/单子代理可完成 | **`2.5.1`（规划）…`2.5.n`（清理）** |

2026-09-26：`0.2.5`→`2.5`；新周期 `2.x.1`=规划；旧 `0.2.5-A`≈首实现 `2.5.2`。字母阶段仅归档检索，新开周期勿再写字母。

---

## 2. 产品档完成门（现行）

| 档 | 完成门 |
|----|--------|
| v1 | 已封 |
| v2 | 其下实现周期（现行 **2.1–2.7**）均收口 |
| v3 | 仅 v2 后开 |
| 其后 | 非现行授权 |

下一产品档 / 下一实现周期：须上一完成，或用户改边界并确认。

---

## 3. 阶段表「类型」列（强制）

取值**只能**三选一：

| 位置 | 类型 |
|------|------|
| 序号最小（`2.x.1`） | **规划计划版** |
| 中间全部 | **实现版** |
| 序号最大 | **清理总结版** |

禁止漏列类型；禁止首行/末行标成实现。  
草案阶段表 **≠** 已审；正式确认在规划版 **P1→P2**（见 [planning-gates.md](./planning-gates.md)）。

周期完成：仅当清理总结版全部测试与归档通过（见 [layers.md](./layers.md) §清理）。
